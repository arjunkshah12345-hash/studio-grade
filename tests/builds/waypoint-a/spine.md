# Waypoint: Design Spine (waypoint-a)

Brief facts used (and only these): an AI guide that onboards new engineers to a codebase. It reads the repository, the docs and the last year of pull requests. It answers a new hire's questions in Slack, linking to the exact lines. It keeps a living map of the services and who owns each one. It writes a first-week plan of small, real tasks. It only reads: it never pushes code or merges anything. Works with GitHub, GitLab, Slack and Microsoft Teams. Setup: install the GitHub or GitLab app and pick the repos (about 5 minutes); the first map is ready in about 20 minutes for a mid-sized repo. Pricing: Free under 50,000 lines; Team USD 20 per engineer per month; Enterprise by quote, with self-hosting. Audience: engineering managers and staff engineers at 20–500-engineer companies that hire often. Primary "Map your repo", secondary "See a first week". No customers, logos, testimonials, time-saved figures or user counts. All data inside mock-ups is example data and is labelled "Example".

The idea in one line: **the codebase as orienteering terrain.** A new hire is dropped into unfamiliar ground. Waypoint is the printed map plus the course setter's magenta overprint: start triangle, numbered control circles, finish double circle. The orienteering map's own legend gives the page a colour logic that means something (open ground, thicket, water), and the magenta overprint is the one accent.

## Copy deck (key lines, all from brief facts)

- **h1:** Day one, with a map.
- **Lede (≤25 words):** Waypoint reads your repo, your docs and the last year of pull requests, then answers new hires in Slack with links to the exact lines.
- **Setup line:** About 5 minutes to install. First map in about 20 for a mid-sized repo.
- **Works-with strip:** Works with GitHub or GitLab, and Slack or Microsoft Teams. It only reads.
- **Why statement (two-tone):** "Every answer already exists." / "It's in a pull request from March, or in the head of the one person who wrote it."
- **Chapter A:** "Asks in Slack. Answers with line numbers." / "Each answer cites the file, the lines and the pull request that explains them, so a new hire can check it, not just trust it."
- **Chapter B:** "A map that redraws itself." / "Waypoint keeps a living map of your services and who owns each one, so the question 'who do I ask?' has an answer too."
- **First week:** "A first week of small, real tasks." / "Five controls, start to finish. Each one touches real code and names who to ask."
- **Trust:** "It reads. It never writes." / "No pushes, no merges, ever. On Enterprise, run it on your own infrastructure."
- **Finale:** "Give the next hire a map."
