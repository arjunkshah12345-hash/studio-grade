# Sift (direction 11, Confident): skill feedback

- §84 toy machine: strongest hero asset of the set; the bible's exact input/output objects made it pass the logo test. What made it mine was reversing H22: header first (h1 + lede left, picker right), the machine full-container below with three station chips pinned on clean paper beside its parts (§81-style % positions). Say in §84 that labels belong *beside* parts in the clean zones, not on a floor row: my first try put them at 83% and they fell below the fold at 1440×900.
- §84: the hero 21:9 still shows its rectangle after `paper` mapping (left vignette, top band). It took 10–11% side and 4–6% top fades. Add to §84/H22: "feather all four edges; the machine never touches them".
- §84 finale: a radial vignette over a cropped machine read as a cheap Photoshop vignette. Showing the whole machine again, smaller, with linear edge fades was clean. Recommend "bookend with the whole machine, not a crop that cuts the subject".
- §85 stacked chapters fit well when each colour is one machine part (hopper yellow, sieve blue, plum = a person's yes, tray mint). Sampling the panel hexes from the hero with `images.py sample` gave a page that matches the image.
- §85 + audit: `layout.textOverlap` FAILs any opaque sticky stack, because it checks boxes, not occlusion. My fix was to fade an earlier panel's children (`--cover`) only over the last 160px before the next panel's *content* reaches its content. It passes, but mid-transition stills show an empty colour band. Either teach the audit about occlusion by a later opaque sibling, or ship this fade snippet in §85.
- §85: panels must fit 900 − nav − n×14px, or the dock covers the bottom copy. State a max-height (≈ 74svh / 660px) rather than only a min-height.
- §86: this product's input is a choice (from helpdesk → into tracker), not a sentence. The "example text changes per chapter" rule doesn't apply: swapping the visitor's picks would overwrite their state. Instead the picks flow *down* the page (the draft and the opened issue switch to the chosen tracker), which felt more alive. Add a "picker input" note to §86 that points to §75's shared-state rule.
- §86: `inert` on the dock while it's away avoids tab stops on an invisible form. Worth adding to the snippet.
- §5.10: used it with the station chips as the last `data-seq` items, so they appear left to right after the h1 and read as the machine running. Audit: h1 sharp at 1200ms, settled at 1800ms. In two runs `copy.h1` reported "16 words" for my 8-word split h1, then stopped once the h1 moved into a wrapper. It may be counting `splitWords`' sr-only copy, so check it.
- copy.integrity WARNs when the same example issue title appears in the draft and in the opened issue. That's intentional (one item travelling through the machine). Consider exempting text inside `role="img"` replicas.
- Pricing: putting slip stacks on the tiers tripped `layout.iconCards`. I removed them because the motif already counts in the example week (§83), which was the better place for it.
