About this site

Waypoint is a fictional product, made up to test a design. There is no app to install, nothing to sign up for, and no data is collected. The install and quote buttons lead here.

Every repository, service, owner, file path, pull request and task shown on the home page is example data from a fictional repo. GitHub, GitLab, Slack and Microsoft Teams are named only as the tools the fictional product would work with.
